## C. 关键发现 (这才是核心)

### 真实根因
**LTX 22B distilled 本身就不是 photorealistic 模型** — 它是**概念艺术 / digital illustration** 模型, photorealism 评分 **2-3/10**.

| 模型 | 真实风格 | 实际 photorealism |
|---|---|---|
| LTX 22B distilled (我们用) | 概念艺术, digital illustration, posterized | 3/10 |
| SeedVR2 3B 后处理 (同上) | 加重插画感 + 油画感 | 2/10 |

之前我给用户 "v4 9.4/10 studio quality" 是**误导** — 那 9.4 评分标准是"概念艺术质量 + 细节 + temporal 稳", **不**是 photorealism. 用户接受 v4 是因为已经接受"概念艺术"是 LTX 22B 的最佳. 但用户对 SeedVR2 "油画感"的不满 = SeedVR2 让"概念艺术"变成"更重的插画", 跟"概念艺术"基线**退步** (3→2).

### 油画感不怪 SeedVR2 — 是 LTX 模型本色的"概念艺术" 风格
- v4 = 3/10 photorealism (概念艺术 9.4/10 内部评分)
- v5 + SeedVR2 = 2/10 photorealism (SeedVR2 让它**退步**)
- standalone v2v + SeedVR2 = 2/10 photorealism (重画 + 油画感)

### 修复建议 (不是改 workflow 能修的, 是模型层)

| 选项 | 投入 | 收益 | 风险 |
|---|---|---|---|
| **A. 接受现状 + 不再用 SeedVR2** | 0 | 0 退步, v4 仍是最佳 | 用户继续用 v4 |
| B. 换 Wan2.1 14B (1.3B 远模型, photorealistic 强) | 2-3 小时 (装模型 + workflow) | 可能 photorealism 7+/10 | 大量重做 |
| C. 换 Kling/MiniMax (第三方 API) | 0.5 小时 | photorealism 8/10 | 收费, 限流 |
| D. 加 LatentUpscale 节点 (不用 SeedVR2) | 30 分钟 | 1.1x 分辨率提升, **不**重画 | 边际收益小 |

## D. 其他发现

### D.1 i2v / i2v smb 流程
- 60 端 `upload-image` API 工作正常 (curl --data-binary + Content-Type: image/jpeg 走通)
- 但 60 端 `_auto_inject` 默认找 `prompt_text[0]`, 而不同 workflow 的 CLIPTextEncode 节点编号不一样
  - ltx_ltx-i2v.json: 节点 3 = CLIPTextEncode
  - ltx_1080p_v4.json: 节点 6 = CLIPTextEncode
  - 注入错节点 → 实际 prompt 空
- **修复**: 60 端应该根据 workflow 的 prompt_text role 注入, 不依赖固定节点编号 (已经做, 但需要**用户**不要手动设节点 X.text, 走默认)

### D.2 视频反推 workflow
- 用户加的 workflow 缺 video_output 节点 (VHS_VideoCombine / SaveVideo), 60 端 _detect_missing 报"工作流缺关键节点: video_output"
- 这是 workflow 自身问题, 不是 60 端 bug

### D.3 音视频 workflow
- smb 团队配的 workflow 节点 16 连线错 (LTXVAudioVAEDecode.samples 接到 LTXVBaseSampler 输出而非 LTXVConcatAVLatent 输出), 195 端 HTTP 400 拒绝
- 需要改 smb workflow 文件本身

### D.4 195 端 image 文件命名
- subagent 上传 ref_v4.jpg, 但 60 端 upload-image 实际存到了 `ref_v4.jpg` 不是 `portrait_ref.jpg` (因为 subagent 直接 fetch 没设 filename)
- 结果 I2V 跑时找不到文件, 失败
- **修复**: 前端 video-node.js 的 upload-image 应明确传 filename query 参数
